# SYSHHB IT Portal System

This is a static Progressive Web App. The archive includes the portal page, install manifest, offline service worker, and Yayasan app icons.

## Publish with GitHub Pages

1. Extract the ZIP and upload all files to the root of a GitHub repository.
2. In the repository, open **Settings → Pages** and enable publishing from the `main` branch and `/ (root)` (or the branch you uploaded to).
3. Open the HTTPS GitHub Pages address in Edge or Chrome. Use the browser’s **Install app** option or the portal’s install prompt when available.

The installable app requires HTTPS. The `file://` preview is for viewing only and cannot be installed as a PWA.
